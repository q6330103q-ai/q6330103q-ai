## 소개

실시간 렌더링 기반의 **스타일라이즈드 환경 아트**를 다룹니다.
아트와 엔지니어링이 만나는 지점에 관심이 많아서, 반복되는 에셋 작업을
재사용 가능한 유니티 시스템으로 바꾸는 작업을 즐깁니다.
다시 만드는 대신 다듬는 데 시간을 쓸 수 있도록 만드는 게 목표입니다.

- 🎮 현재 **[프로젝트명]** 의 환경 아트를 담당하고 있습니다
- 🌱 **Shader Graph**, **C# 에디터 툴**, **프로시저럴 워크플로우** 를 공부 중입니다
- 🎯 올해 목표는 **완성도 있는 버티컬 슬라이스 하나를 끝까지 마무리하기** 입니다
- 💬 **모듈러 킷**, **트림 시트**, **URP 라이팅** 에 대해서라면 언제든 이야기 나눠요
